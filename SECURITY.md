# Security Policy

## Supported Versions

Security fixes are made for the latest minor version only. As long as jxt is
below 1.0, each minor version may contain breaking changes.

| Version | Supported |
| ------- | --------- |
| 0.5.x   | yes       |
| < 0.5   | no        |

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues. Use
[private vulnerability reporting](https://github.com/smarta-lab/jxt/security/advisories/new)
on GitHub instead.

You will get a reply within a week. Once the issue is confirmed, a fix is
released as a patch version and published with a security advisory.

jxt is a development tool and is not meant to run on production servers; this
applies to the jxt bridge plugin as well.
